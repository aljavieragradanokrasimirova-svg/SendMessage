# Cómo usar SendMessage

1. Abre **SendMessage** y escribe un nombre debajo de «Escribe el remitente».
2. Escribe el texto debajo de «Escribe tu mensaje».
3. Pulsa **Enviar mensaje**. La segunda pantalla mostrará el remitente, el mensaje y un dibujo de un bocadillo de chat.

Para escribir otro mensaje, utiliza el botón o gesto de volver del teléfono.

El mensaje se muestra dentro de la misma aplicación. No se envía a otras personas y no queda guardado como un historial.
